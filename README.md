# Automated Test Suite

A UI automation exercise covering a standard e-commerce purchase flow on the SauceDemo sample application.

## Scenario covered

1. Sign in with a standard test user.
2. Select three products.
3. Add the products to the cart and verify the cart contents.
4. Continue to checkout.
5. Enter checkout information.
6. Complete the purchase and assert that the success message appears.

## Scope

The scenario is intended to exercise the main purchase path from login through order confirmation. The current README does not identify the automation framework, dependency versions, or exact run command, so those details should be confirmed from the test files and project configuration before running the suite.

## Test environment

Use the public SauceDemo sample application and its documented test credentials. Do not use real customer accounts or personal information.
